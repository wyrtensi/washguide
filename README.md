# washguide

Справочник по старым электромеханическим стиральным машинам с непонятной панелью:
ручки с цифрами или буквами, кнопки без подписей, нет дисплея. На странице машины видна её панель
и лоток. Ручки можно крутить прямо на рисунке, а страница считает время, проверяет
конфликты настроек и показывает, как машина закончит цикл.

## Структура

```
data/machines/<id>.json   данные машины, формат в docs/schema.md
src/engine.js             логика: обход шагов таймера, время, конфликты, поиск (общая для сборки и браузера)
src/render.js             SVG панели, лоток, карточка результата (общая для сборки и браузера)
src/app.js                интерактив в браузере
src/style.css             стили, светлая и тёмная тема
scripts/build.mjs         сборка dist/ и проверка данных
scripts/test-engine.mjs   тесты движка
scripts/serve.mjs         локальный сервер для dist/
docs/spec.md              дизайн
research/                 рабочие материалы исследования (PDF инструкций, выдержки), в сайт не попадают
```

Внешних зависимостей нет, нужен только Node 18+.

## Команды

```bash
npm test                   # тесты движка
npm run check              # проверка всех data/machines/*.json
npm run build              # сборка в dist/
node scripts/serve.mjs     # http://localhost:4173/
```

`SITE_URL=https://example.org npm run build` проставляет абсолютные ссылки в `llms.txt`
и canonical, а также создаёт `sitemap.xml`.

## Как добавить машину

1. Найдите инструкцию производителя (PDF) и фото панели.
2. Скопируйте любой файл из `data/machines/`, переименуйте в `<марка>-<модель>.json`
   и заполните по `docs/schema.md`. У каждого значения из инструкции должен стоять номер страницы.
   Всё, что оценено, отметьте в `notes.assumptions`, а чего нет в инструкции — в `notes.gaps`.
3. Запустите `npm run check`: проверка поймает несуществующие позиции, отсеки и цепочки шагов без конца.
4. Запустите `npm run build`, откройте страницу машины и сверьте панель с фото.

## Для агентов и поисковиков

Сборка создаёт `llms.txt` (как пользоваться сайтом и данными), `llms-full.txt` (все машины текстом),
`machines.json`, `search-index.json`, `m/<id>.json`, а также `robots.txt`, где AI-краулеры
разрешены явно. На каждой странице есть JSON-LD и блок `sr-only` с подсказкой для агентов.
Этот блок скрыт визуально, но в DOM он есть: это не клоакинг через `display:none`.

Ссылка на конкретную настройку: `m/<id>/?p=4&t=40&s=600&o=half` или `m/<id>/?preset=everyday-40`.

## Хостинг

`dist/` — чистая статика: подойдут GitHub Pages, Cloudflare Pages, Netlify или любой nginx.
Ссылки внутри относительные, поэтому сайт работает и из подкаталога.
